## 0.1.0(23)

- chore: 脚本执行总超时由 5 秒放宽到 30 秒
- feat: 优化键盘脚本结果页显示效果
- feat: 工具栏新增「剪贴板提示栏」
- feat: 剪贴板长按菜单（包含新增的剪贴板提示栏）新增：「提取验证码」，「分词」选项

## 0.1.0(21)

- fix: 浮动候选栏候选的首选背景色与按下时背景色使用皮肤中设置颜色
- fix: 轻点候选字滑块初始位置写入字号 0 ，导致候选字不显示
- fix: 成对符号并光标居中功能，在 ChatGPT 下行为异常，光标会落在前一个文字的前方
- fix: 触感风格选项改为中性的「风格一」 / 二 / 三，避免与厂商调校的体感不符
- 优化: 「划动调整预编辑光标位置」功能优化
- 优化: 调整「手动分页」模式下，候选栏手动翻页箭头大小，按钮位置
- 优化: 剪贴板/常用语与候选字长按菜单底色改为与面板一致
- feat: 优化键盘剪贴板 / 常用语面板 UI
- feat: 皮肤长按菜单新增「跳转皮肤目录」「应用日志」菜单
- feat: 内嵌模式新增「横向浮动」候选项，「浮动顺序」 / 「倒序」改名为「纵向浮动」

## 0.1.0(20)

- 优化: 浮动候选窗最小宽度改为按候选字号取两个汉字宽
- 优化: 键盘高度设置功能，设置高度等于皮肤按键区高度，键盘总高度 = 设置高度 + 工具栏高度 + 预编辑区高度

## 0.1.0(19)

- fix: 删除按键音与震动页的按键气泡开关，仅在键盘设置页保留
- fix: 优化字体设置页面，修正字符区间预设
- feat: 内嵌模式下预编辑显示首个候选项时，可隐藏候选栏首个候选
  - 默认：关闭状态，如果需要隐藏候选字栏中的首个选项，可开启此选项
- 优化: 浮动候选窗优化
  - 分页按键开关、最小宽度、高亮圆角同心
  - 加大行间距，高亮背景不再与相邻候选紧挨
  - 修复首次显示在部分应用下会跳动
