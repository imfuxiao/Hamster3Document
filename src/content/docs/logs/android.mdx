## 0.1.0(10)

- feat：输入行为新增「密码框默认英文输入」开关。默认开，表示密码框下输入内容直接上屏，关闭后，输入内容会发送 RIME 引擎。
- 修复：内置文本编辑器滚动后又自动回到光标 / 原来的位置
- 修复：应用内链接 hamster3:// 的页面参数未生效
- chore：关于页版本号显示 versionCode，格式 0.1.0(9)
- 修复（不确定，无法验证）：HyperOS 自绘导航栏的 ROM 上键盘底部没有安全区域

## 0.1.0(9)

- 修复：文件管理子目录中点左上角返回键回到上级目录而非主页
- 修复：内置文本编辑器拖动不跟手、关闭后键盘不收起
- 修复：#行首 / #行尾 指令移动到文档首尾而非当前行首尾
- feat：Rime 同步目录可选择手机上任意目录（SAF + 镜像）
- feat: 震动功能优化

## 0.1.0(8)

- 修复：Chrome 地址栏等网址框固定英文键盘，中英切换键无法切回中文
- 修复：cartoon / physics 设置 targetScale 时图片显示尺寸与 iOS 不一致
- 修复：无导航栏与手势区 inset 的 ROM 上底排按键被屏幕圆角切掉
- 修复：subClassifiedSymbols 全角角标位置与样式按 iOS 实现
- 修复：集合单元格前景样式无 text 时不显示符号 label
- 修复：HyperOS（Android 13）下图标显示为连字名称
- 修复：主页 Wi-Fi 传输横幅地址重复拼接协议与端口
- 修复：方案目录切换支持 RimeUserData 下任意层级目录
- 修复：floatKeyboardType 浮动键盘按 iOS 行为实现
