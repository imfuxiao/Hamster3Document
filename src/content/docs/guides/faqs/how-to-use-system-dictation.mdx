---
title: 系统语音听写如何添加粤语支持？
---

import { Aside } from '@astrojs/starlight/components';

如果在元书键盘中使用系统语音听写时，识别语言为普通话，而你希望使用粤语，可以按照以下步骤调整。

## 开启粤语听写

1. 打开系统 **设置 → 通用 → 键盘**。
2. 开启 **启用听写**，并按系统提示确认；如果已经开启，可跳过此步。
3. 进入 **听写语言** 页面，勾选需要的粤语选项，例如 **粤语（香港）**。
4. 返回输入框，点击键盘右下方的 **麦克风按钮**，开始听写。如果启用了多种听写语言，请先确认当前选择的是粤语。

## 切换听写语言

当启用多种听写语言后，可以通过以下方式切换：

- **开始听写前**：长按麦克风按钮，在弹出的语言菜单中选择粤语。
- **开始听写后**：点击输入光标附近的听写状态栏，在可用的语言选项中切换到粤语。


<Aside type="note" title="词典设置建议（尚未验证）">
据说调整系统词典可能提高粤语听写的识别率：打开 **设置 → 通用 → 词典**，保留 **繁体广东话**，取消勾选其他不需要的语言词典。此说法尚未经过验证，仅供尝试，并非开启粤语听写的必要步骤；
</Aside>
