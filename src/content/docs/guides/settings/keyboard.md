**入口：元书首页 →「键盘设置」。** 修改界面选项后，回到普通文本输入框，收起并重新唤起键盘检查效果；不需要为这些开关修改方案文件。

## 候选字太小，怎么放大

1. 打开「键盘设置」，找到「候选文字」卡片。
2. 调整候选文字对应的字号滑块，观察卡片上的预览。
3. 如果序号或拼音注释太小，分别调整「候选索引」「候选 Comment」对应的字号。

字号滑块当前可调范围为 12～26。字号增大后，一行能放下的候选字会减少，需要更多翻页，这是正常现象。

- **候选文字**：等着你选择上屏的字或词。
- **候选索引**：候选项旁的序号。
- **候选 Comment**：方案提供的拼音、编码、提示等注释，不一定只显示拼音。
- **预编辑字符（仅在关闭内嵌时有效）**：键盘上显示的未上屏编码。这里的字号不控制宿主应用输入框里的文字大小。

只想改字体样式而不是大小，请看[皮肤与字体](/apps/hamster/v3/docs/guides/settings/skins-fonts/)。

## 不想显示候选词旁边的拼音或数字

**入口：「键盘设置」→「候选文字」卡片。** 「候选索引」和「候选 Comment」各有一个显示开关，旁边的字号滑块只负责大小，不代替显示开关。

### 「候选索引」显示开关

- **开启**：显示候选项的序号或选择标签，例如候选词旁的 `1`、`2`、`3`，便于辨认候选项；具体标签由当前方案提供。
- **关闭**：隐藏这些序号或标签，候选词仍然显示，也仍可点按选词。
- 默认关闭。开启后，可用「候选索引」对应的字号滑块单独调整标签大小。

这个开关只控制键盘候选栏中的标签，不控制当前应用输入框里内嵌预编辑文本的「显示候选序号」。

### 「候选 Comment」显示开关

- **开启**：显示方案为候选项提供的注释，例如拼音、编码或其他提示。方案没有提供注释时，打开开关也不会自动生成拼音。
- **关闭**：隐藏候选栏中的注释，仅保留候选文字和其他已开启的显示内容，不会删除词库信息或改变候选词本身。
- 默认开启。需要放大或缩小注释时，调整「候选 Comment」对应的字号滑块，而不是候选文字的字号。

这只是改变显示，不等于修改 RIME 方案中的注释生成逻辑。当前应用输入框中的内嵌预编辑文本也显示注释时，还要检查下文的「显示候选注释」，两处开关分别控制不同区域。

## 候选词挤在一起，怎么调整间距

**入口：「键盘设置」→「候选文字」卡片 →「候选文字间距」。** 使用加减控件调整，当前界面范围为 **0～100**，每次增减 **1**，默认间距为 **6**。

这里调整的是**相邻候选项之间的间隔**，不是一个候选词内部各个汉字之间的字距，也不是字号或键盘高度。

- 设置为正数时，数值越大，候选项之间越宽松，同样宽度下通常能显示的候选项越少。
- 希望排列紧凑时，可以逐步减小正数值，再回到键盘查看效果。
- **设为 `0` 是取消自定义间距，回退到默认值 `6`，并不表示候选项之间没有间隔。**

显示开关、字号和间距调整会直接保存，无需额外点击「保存」。修改后收起并重新唤起元书键盘，输入同一段编码对照候选栏；实际排布也受皮肤布局、候选词长度和字号影响。

卡片中的「重置」会一并恢复相关字号、候选索引与 Comment 显示开关，以及候选文字间距，不是只重置间距。

## 拼音显示在输入框里，还是键盘上

**入口：「键盘设置」→「内嵌输入模式」。**

| 选项 | 效果 | 适合什么情况 |
| --- | --- | --- |
| 开启 | 未上屏文本内嵌显示在当前应用的输入框中 | 希望在正在编辑的位置看到拼音或编码 |
| 关闭 | 未上屏文本显示在键盘预编辑区中 | 不希望未确认的内容进入应用输入框，或某个应用内嵌显示异常 |

开启内嵌后，会出现「显示候选字栏」和「预编辑」相关设置。看不到这些项目时，先确认内嵌输入模式已开启。

### 开启内嵌后，如何控制输入框中的预编辑内容

这些选项控制的是**当前应用输入框中的未确认文本**，不是键盘上的预编辑区。开启内嵌后，键盘自身的预编辑区不再显示这些文字。

在「内嵌输入模式」卡片内找到「预编辑 → 显示内容」，可以选择：

- 预编辑文本；
- 首个候选项；
- 全部候选项；
- 预编辑文本与首个候选项；
- 预编辑文本与全部候选项。

想同时看到编码和首选词，可以选择「预编辑文本与首个候选项」。这里只决定输入框中未确认的文本显示什么，**不代表候选词已自动上屏**。联想状态下的候选项不会纳入这段内嵌文本。

### 不想让首选词显示两次

1. 开启「内嵌输入模式」。
2. 将「显示内容」设为「首个候选项」或「预编辑文本与首个候选项」。
3. 打开出现的「隐藏候选栏首个候选项」开关。

这样，首选词仍可显示在当前应用输入框的内嵌预编辑文本中，候选栏不再重复显示它。切回其他显示内容后，该开关会隐藏，并非设置丢失。

### 内嵌预编辑文本的注释和序号怎么控制

- 显示内容包含候选项时，才会出现「显示候选注释」。
- 选择「全部候选项」或「预编辑文本与全部候选项」后，才会出现「显示候选序号」。
- 序号可设为「从不」「始终」，或候选数量超过 1、2、3 个时显示。

这些设置不等于上方「候选文字」卡片中的「候选索引」「候选 Comment」。前者控制当前应用输入框中的内嵌预编辑文本，后者控制键盘候选栏。

### 候选字栏不见了怎么办

如果是在开启内嵌输入后不见的，进入同一卡片，重新打开「显示候选字栏」。不要先重置方案或重装应用。

## 候选字横着排，还是竖着排

**入口：「键盘设置」→「候选字显示模式」。**

选择「水平显示」或「纵向显示」，按页面示意图确认效果。纵向模式下还可调整「候选字居上」。这是候选显示方式，不是切换九宫格或全键盘的入口。

## 候选字怎么翻页，展开按钮怎么找回来

**入口：「键盘设置」→「候选字分页模式」。**

- **划动分页**：通过划动候选区域翻页。
- **手动分页**：使用手动翻页方式；选择后才出现「显示分页按键」。

如需显示翻页按键：

1. 选择「手动分页」。
2. 打开「显示分页按键」。
3. 如还想保留候选栏展开按钮，关闭「隐藏候选栏展开按键」。

「隐藏候选栏展开按键」只在手动分页且开启分页按键时出现。它隐藏的是展开入口，不是删除候选字，也不是关闭翻页能力。

## 键盘太高或太矮，怎么调整

1. 进入「键盘设置」→「键盘高度设置」。
2. 拖动预览键盘上的高度调节手柄，调整到合适大小。
3. 点击「保存」。点击取消或页面空白处退出，不等于保存。

这里设置的是**按键区域的高度**，键盘总高度还包含工具栏、预编辑区及底部留白，所以显示出的总高度不一定等于调节值。

「重置」会清除自定义高度，回到当前皮肤定义的高度，不是恢复整套应用设置。

## 上下滑动按键经常误触，或怎么滑都没反应

**入口：「键盘设置」→「滑动参数设置」→「按键滑动手势设置」。**

- **滑动最小距离**：手指至少要移动多远。
- **滑动最小速度**：手指至少要滑多快。

**距离和速度必须同时超过设定值**，才会识别为有效的上下滑动。

- 经常误触：小幅增大阈值。
- 很难触发：小幅减小阈值。
- 调乱了：使用该页面的「重置」，不要重置整个应用。

一次只改一个参数，并在同一个按键上反复试。参数只改变手势识别，不会替皮肤给按键新增上下滑动动作；皮肤没有配置动作时，调得再灵敏也不会出现该功能。

## 其他键盘开关

| 选项 | 用途与注意事项 |
| --- | --- |
| 按键气泡 | 控制按下按键时的提示气泡；不是按键音或震动开关 |
| Shift 状态锁定 | 调整 Shift 状态的保持行为；不是切换 RIME 中文／英文模式的开关 |
| 脱字符（‸） | 控制预编辑光标提示的显示 |
| 划动调整预编辑光标位置 | 调整尚未上屏文本中的光标位置，不是任意移动宿主应用全文的光标 |
| 键盘日志 | 排查键盘问题时记录日志；复现问题后可关闭，分享前先检查是否含个人内容 |

不确定改动是否正确时，先返回[常见设置问题](/apps/hamster/v3/docs/guides/settings/faq/)，不要直接执行方案重置。
