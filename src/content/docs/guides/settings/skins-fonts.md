## 怎么更换键盘皮肤

**入口：元书首页 →「键盘皮肤」。**

1. 在皮肤列表中选择想使用的皮肤。
2. 回到输入框，重新唤起元书键盘。
3. 检查外观、主键盘布局以及常用功能入口是否符合预期。

**皮肤决定外观和按键布局，输入方案决定编码与词库。** 使用双拼、九键时，仍需选择相匹配的 RIME 方案。不能只换一个九宫格外观就认为九键已经配好。

## 下载的皮肤文件怎么安装

1. 先将皮肤包保存到 iOS「文件」应用能找到的位置。
2. 进入「键盘皮肤」，打开右上角「⋯」菜单，选择「导入皮肤」。
3. 选中皮肤包，按导入确认页面完成操作。
4. 导入后回到皮肤列表，选择刚导入的皮肤。

导入文件与选中使用是两个步骤。如果导入后仍是原来的键盘，先检查当前选中的皮肤，不要反复导入。

皮肤格式、配置与开发说明见[键盘皮肤简介](/apps/hamster/v3/docs/guides/skins/intro/)。

## 怎么让键盘一直用深色或浅色

**入口：「键盘皮肤」→ 右上角「⋯」→「颜色模式」。**

可以选择：

- **跟随系统**：跟随键盘从当前应用收到的外观设置，可能受该应用的深浅色模式影响，不保证始终与设备全局外观一致。
- **浅色**：使用皮肤的浅色样式。
- **深色**：使用皮肤的深色样式。

选择深色后配色不明显，可能是皮肤的浅深色设计本来接近。此选项选择已有样式，不会自动为皮肤重新设计一套颜色。

## 为什么换了皮肤，工具栏还是旧的

如果启用了自定义工具栏，应用中的工具栏配置会覆盖皮肤中的工具栏选项，但不覆盖工具栏背景样式。

希望使用皮肤原本的工具栏时，进入「工具栏设置 → 设置」，关闭「启用自定义工具栏」，再回到键盘检查。详见[工具栏与菜单](/apps/hamster/v3/docs/guides/settings/toolbar-menu/)。

## 皮肤的 iCloud 复制与开发模式怎么用

皮肤页菜单提供「复制本地皮肤至iCloud」「复制iCloud皮肤至本地」。这是有方向的复制操作，不要把它当作自动双向合并。操作前确认哪一份是要保留的版本，重要皮肤先用「分享皮肤」单独导出保存。

「启动皮肤开发模式」仅供使用 Jsonnet 开发皮肤时调试。普通用户安装、切换皮肤无需开启，也不要把它当作“应用皮肤”或“刷新键盘”的按钮。

「重置内置键盘」用于还原内置皮肤文件，不是还原 RIME 输入方案。自己改过内置皮肤时，先导出副本再操作。

## 字体已经导入，为什么键盘没有变化

**入口：元书首页 →「键盘字体」。** 这里有三个页面，必须区分：

| 页面 | 做什么 |
| --- | --- |
| 字体文件 | 导入和管理字体文件 |
| 键盘字体 | 把字体文件或系统字体加入键盘实际使用的字体配置 |
| 设置 | 打开「启用键盘字体」总开关 |

只完成「导入字体文件」，并不代表已经配置键盘使用它。

### 使用自己导入的字体

1. 打开「键盘字体 → 字体文件」。
2. 在右上角菜单选择「导入字体文件」，选择字体文件。
3. 切换到「键盘字体」页面，右上角菜单选择「选择字体文件」，把字体加入列表。
4. 切换到「设置」，打开「启用键盘字体」。
5. 回到输入框，重新唤起元书键盘检查。

### 使用系统字体

进入「键盘字体 → 键盘字体」，从右上角菜单选择「选择系统字体」，选好后再确认「设置 → 启用键盘字体」已开启。

### 只有部分文字变了字体怎么办

字体不一定包含所有汉字、符号或 emoji。可以检查：

- 字体文件信息中的文字预览和字形数量。
- 「键盘字体」列表中各字体的顺序，可拖动右侧排序控件调整。
- 对字体文件条目设置的「字符范围设置」是否覆盖希望使用的字符。

字符范围中的「字符编码」支持十进制或 `0x` 开头的十六进制，「字符长度」表示从起始编码开始覆盖的数量。不了解编码范围时，先不要随意限制。

此功能只设置键盘所用字体，不会修改微信、备忘录等应用正文的字体。候选字大小请到「键盘设置 → 候选文字」调整。

## 怎么修改元书的桌面图标

**入口：元书首页 →「应用图标」。** 在页面中选择图标。想恢复默认图标，可从右上角菜单执行「重置应用图标」，不需要执行「重置应用设置」。
