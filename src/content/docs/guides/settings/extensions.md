**入口：元书首页 →「扩展功能 · PRO」。** 以下功能需要检查 Pro 状态；在键盘中使用时，还应在系统键盘设置中开启元书「允许完全访问」。

## 应用里有功能，为什么键盘上找不到

应用页负责管理内容，键盘需要一个能打开该功能的按键入口。可以到「工具栏设置」或「键盘菜单设置」添加相应动作。

例如：常用语为 `#showPhraseView`，剪贴板为 `#showPasteboardView`，脚本面板为 `#toggleScriptView`，命令面板为 `#toggleCommandView`。这些是配置标识，不是在聊天里发送的文字。

操作步骤见[工具栏、键盘菜单与符号栏设置](/apps/hamster/v3/docs/guides/settings/toolbar-menu/)。

## 怎么添加一句常用回复

**入口：元书首页 →「常用语」。**

1. 新增一条常用语，填写正文。
2. 按需填写标题，方便命令面板搜索或短语指令引用。
3. 需要整理大量内容时，设置分类、标签。
4. 保存后，在键盘常用语面板或命令面板中找到并使用它。

标题可选，但需要通过短语指令使用名称时应填写。动态变量、模板和导入导出见[常用语](/apps/hamster/v3/docs/guides/phrase/)。

## 脚本怎么配置，为什么运行不了

**入口：元书首页 →「脚本」。** 管理脚本后，可以从键盘脚本面板或命令面板中执行，也可绑定到工具栏动作。

遇到问题，先检查：

- 是否保存脚本，脚本名称是否与所绑定的动作一致。
- Pro 与完全访问权限是否满足。
- 脚本自身依赖的网络、参数、文件或数据是否已准备好。
- 是否仅在某个输入场景中缺少选中文字等输入。

只导入可信来源的脚本。脚本能做什么、使用哪些参数，应先查看脚本内容与[脚本说明](/apps/hamster/v3/docs/guides/scripts/)。

## 命令面板的前缀怎么改

**入口：元书首页 →「命令面板」→「子模式前缀」。**

| 子模式 | 默认前缀 |
| --- | --- |
| 常用语 | `/` |
| 剪贴板 | `@` |
| 脚本 | `$` |
| 动作 | `#` |
| AI、AI 历史消息 | 默认为空，可使用面板入口 |

设置后的非空前缀不能与其他子模式重复。输入框标红时，先消除冲突，再结束编辑。需要恢复默认值时，使用前缀区域的重置入口；这不是重置整套 AI 配置。

这些前缀要在**键盘命令面板内部的输入框**使用，不是普通聊天框中的机器人指令。动作列表可配置名称与别名，方便检索键盘动作。

## 第一次用 AI，需要先配什么

**入口：「命令面板」→「服务商与模型」。**

1. 选择已有服务商并编辑，或点击「＋」从模板添加。
2. 填入服务商签发的 **API Token**。模板已经预填地址等常用项时，不必随意改动。
3. 确认「请求 Model ID」是服务商实际提供的模型标识，而不只是自己起的展示名称。
4. 保存后，在服务商操作菜单中运行「连接测试」。
5. 需要时使用「刷新 Model」「选择默认 Model」管理该服务商下的模型。

购买元书 Pro 不等于已经获得第三方模型服务的 API Token 或调用额度；相关费用和配额由对应服务商决定。

:::caution[隐私与密钥]
AI 请求会发送到你配置的服务商。发送前确认提示词引用了哪些输入或剪贴板内容；不要在公开截图中展示 Token，也不要把私人内容随意发给不信任的服务商。
:::

### 自定义服务商时，几个字段怎么理解

| 字段 | 应如何填写 |
| --- | --- |
| HTTPS Base URL | API 基础地址，不包含下方另外填写的 API 路径后缀 |
| API 路径后缀 | 该服务商实际支持的接口路径，避免与基础地址重复拼接 |
| API Token | 服务商签发的访问密钥，不是网站登录密码 |
| Model 展示名称 | 自己在列表里识别模型的名称 |
| 请求 Model ID | 请求实际使用的模型标识，必须匹配服务商接口 |
| 上下文窗口 | 按服务商与模型能力配置，不要只为“记得更多”随意放大 |
| 最大输出 Token 数 | 控制单次生成长度；「不限制」不代表服务商没有上限 |
| 请求超时（秒） | 等待下一段数据的最长时间，不是整段流式生成的固定总时长 |
| Temperature | 调整随机性；不确定时沿用模板设置 |
| 自定义参数 | 可选，必须是合法 JSON object；普通使用先留空 |

只支持填写表单，不代表任意服务商协议都能兼容。遇到错误时按服务商接口要求核对，不要反复更换无关的键盘设置。

## 翻译、润色等 AI 指令怎么设置

**入口：「命令面板」→「AI 指令」。** 一条指令组合三个必选项：

1. **系统提示词**：规定角色、规则和回答风格。
2. **用户提示词**：规定如何包装待处理输入，可以使用页面提供的模板变量。
3. **Provider 提供商**：决定发送到哪个服务商及模型。

先在对应页面准备这些内容，再新建 AI 指令，填写不重复的名称，选齐三项后保存。需要一键使用时，再将该 AI 指令绑定到工具栏项。

如果列表提示“引用的提示词或服务商已失效”，编辑指令，重新选择有效项目。提示词停用后，不会出现在对应选择中。

## 历史会话与重置要注意什么

- 「命令面板 → 历史会话」可以查看、改标题、删除会话。
- 「历史会话存储限制」控制保留数量，不是模型上下文长度。
- 「重置内置服务商」恢复内置定义，不等于清空 Token 或删除自己新增的全部模型。
- 「重置 AI 指令模板」会还原模板指令并补齐引用的内置项目；自建指令不受此操作影响。

如果内置服务商或模板指令的名称已被其他项目占用，对应内置项可能被跳过，不会为了恢复而覆盖同名的用户项目。重置后缺少某个内置项时，先检查名称冲突。

每个重置范围不同，执行前以当前确认框为准。完整使用说明见[命令模式](/apps/hamster/v3/docs/guides/command-mode/)。

## AI 不能用，先查哪几项

1. Pro、完全访问与网络条件是否满足。
2. 服务商是否已填写 Token，是否存在额度、鉴权或模型访问限制。
3. 基础地址与路径是否重复，实际 Model ID 是否正确。
4. 连接测试是否通过。
5. AI 指令引用的提示词和服务商是否仍有效。

不要把应用内 Pro、第三方 API 付费和系统权限当成同一项设置。
