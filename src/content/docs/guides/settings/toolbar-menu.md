## 先分清三个地方

| 功能 | 用途 | 应用入口 |
| --- | --- | --- |
| 工具栏 | 键盘上的一排常用功能入口 | 首页 → 工具栏设置 |
| 键盘菜单 | 打开键盘菜单后显示的功能项 | 首页 → 键盘菜单设置 |
| 符号栏 | 临时显示在键盘上方的快捷符号条 | 首页 → 符号栏设置 |

修改其中一处，不会自动修改另外两处。皮肤按键上的长按或滑动符号，也不是这里的符号栏配置。

## 怎么把一个功能放到工具栏上

**入口：元书首页 →「工具栏设置」。** 页面分为「工具栏项」「键盘工具栏」「设置」。

### 第一步：准备工具栏项

1. 打开「工具栏项」页面。
2. 编辑已有项目，或通过右上角菜单新增项目。
3. 填写名称，选择「按键动作」，按需设置显示图标或显示文字，然后保存。

名称建议使用字母、数字、下划线或连字符，避免不符合 YAML 规则。设置了图片名称时优先显示图标；希望显示文字时，应留空图片名称。

按键动作决定“按下去做什么”，显示图标只是外观。只换图标，不会把按键变成对应功能。

### 第二步：放进实际工具栏并保存

1. 切换到「键盘工具栏」页面。
2. 点选上方可用工具栏项：主要入口为空时，先填入主要入口；已有主要入口时，选中的项目加入其他工具栏项。
3. 需要替换主要入口时，可将上方项目拖到主要入口按钮上。其他工具栏项不支持拖入或拖动排序；需要调整时，先移除相应项目，再按希望的顺序点选添加。
4. 检查下方模拟工具栏的实际排列后，点击「保存」。

仅创建一个工具栏项，不代表它会自动出现在键盘上。工具栏排列页中的「保存」不能省略。

### 第三步：打开总开关

进入「工具栏设置 → 设置」，打开「启用自定义工具栏」。它会覆盖皮肤中的工具栏选项，**不包含工具栏背景样式**。

回到输入框，收起并重新唤起元书键盘，检查新入口。

## 想恢复皮肤自带的工具栏怎么办

关闭「工具栏设置 → 设置 → 启用自定义工具栏」。这与删除自定义工具栏项不同：关闭覆盖即可先对照皮肤原本的效果，不需要清空自己的项目。

## 键盘菜单怎么添加功能

**入口：元书首页 →「键盘菜单设置」→ 右上角「⋯」→「新增菜单项」。**

1. 填写「菜单项名称」。
2. 选择「按键动作」。
3. 选择显示图标，按需调整浅色、深色及按下状态的颜色。
4. 点击「保存」。

返回键盘，打开键盘菜单检查新增条目。右上角菜单还支持导入、导出和「重置菜单设置」。重置前先导出，避免丢失自定义结果。

## 找不到命令面板、常用语或符号栏入口怎么办

这些功能需要一个能触发相应动作的入口。可在工具栏或键盘菜单中添加相应「按键动作」。常见快捷指令为：

| 功能 | 快捷指令标识 |
| --- | --- |
| 打开／关闭命令面板 | `#toggleCommandView` |
| 打开／关闭符号栏 | `#toggleSymbolBar` |
| 打开常用语面板 | `#showPhraseView` |
| 打开剪贴板面板 | `#showPasteboardView` |
| 打开／关闭脚本面板 | `#toggleScriptView` |

这些是**按键动作的配置标识**，不是要求你在聊天输入框里输入这几个字符。常用语、剪贴板、脚本和命令面板还需检查 Pro 状态与完全访问权限。

如果要绑定 AI 动作，应先到「命令面板 → AI 指令」建立指令，工具栏项的 AI 动作选择中才有可选项目。

## 符号栏怎么设置和打开

**配置入口：元书首页 →「符号栏设置」。**

- 在「符号类型」中选择或新增一套符号类型。
- 每套类型固定有 **8 个内容键**，可以修改内容和拖动排序，不能增删内容键数量。
- 点击一个按键，配置中心的点按动作和四角的长按动作。
- 在「布局偏好」中调整高度、内距、颜色和「关闭键在左侧」。

设置完成后，回到键盘执行 `#toggleSymbolBar` 对应的按键动作，符号栏才会显示。**设置页没有一个永久开启符号栏的总开关。**

符号栏的开启状态不会在收起键盘等场景中一直保留；再次使用时需要重新打开。更多使用方法见[符号栏](/apps/hamster/v3/docs/guides/symbol-bar/)。

:::caution[导入符号栏配置会整份替换]
「导入符号栏配置」会替换当前所有符号类型与布局偏好，不是只追加几个符号。请先用「导出符号栏配置」保存自己的版本。
:::

## 改了以后看不见，先检查什么

1. 工具栏项是否只是创建了，但没有放进「键盘工具栏」。
2. 排列后有没有点击「保存」。
3. 有没有开启「启用自定义工具栏」。
4. 当前是在看工具栏、键盘菜单，还是符号栏，是否改错了位置。
5. 功能本身是否还缺少权限、Pro 或前置配置。
