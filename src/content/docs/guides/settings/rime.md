## 输入方案和皮肤有什么区别

- **输入方案**决定编码、词库、全拼或双拼等输入规则，由 RIME 处理。
- **皮肤**决定按键布局、外观和按键动作。

输入方案正确但皮肤不匹配，可能按键不符合使用习惯；皮肤看起来是九键但方案不支持九键，可能只能打出数字。不要只修改其中一项。

## 怎么切换输入方案

**入口：元书首页 → 输入方案卡片／「输入方案」。**

在当前已启用的方案列表中选择要使用的方案。页面只显示当前目录中已启用的方案，不是手机里所有方案文件的清单。

希望添加、移除或排序：

1. 在「输入方案」右上角「⋯」选择「方案列表编辑」；也可以进入「RIME → 方案列表管理」。
2. 在「全部方案（包含依赖方案）」与「已选方案」之间管理需要启用的项目。
3. 拖动排序控件调整顺序，点击「保存」。
4. 认真阅读确认提示：保存会修改 `default.custom.yaml`，其中内容和注释可能发生变化。
5. 确认后等待部署结束，再回到输入方案页面检查并选择目标方案。

不要把所有依赖方案都当成日常输入方案启用。重要自定义补丁请先备份。

## 导入第三方方案后，为什么找不到

**入口：「输入方案」→ 右上角「⋯」。**

可使用「导入方案」导入本机文件，也可使用「下载方案」管理网络下载；电脑传文件还可用「Wi-Fi 文件传输」。详细方法见[输入方案](/apps/hamster/v3/docs/guides/schema/)。

导入后依次检查：

1. 文件是否已放入 `RimeUserData` 下的目标方案目录，且包含必需的方案、词库、依赖文件。
2. 使用「方案目录切换」选择该目录；上传成功不等于目录已经切换。
3. 检查「方案列表编辑」，将目标方案加入已选列表并保存。
4. 等待部署完成，再选择要使用的方案。

同名方案放在不同目录中，也是不同的一套文件。遇到“文件改了没效果”时，先核对当前目录。

## 怎么从全拼切换到双拼

1. 进入「输入方案」，检查目标双拼方案是否已启用。
2. 没有目标项时，到「方案列表编辑」加入对应双拼方案，保存并等待部署。
3. 回到「输入方案」选择它，再到输入框中使用对应双拼编码测试。

只换键帽显示或皮肤，不能完成全拼到双拼的切换。自定义方案还需要其词库与依赖完整。

## 怎么开启中文九键／九宫格

以内置方案为例：

1. 在「RIME → 方案列表管理」启用「中文九键」，保存并等待部署。
2. 回到「输入方案」选择「中文九键」。
3. 在「键盘皮肤」选择匹配的 **T9** 皮肤。
4. 回到输入框测试数字键能否组合出中文候选。

旧版本中缺少内置九键方案或 T9 皮肤时，先备份自己的修改，再按[中文九键](/apps/hamster/v3/docs/guides/chinese-ninekey-configuration/)中的升级说明更新内置资源，不要不看提示就重置。

### 换了九键皮肤，却只能输入数字

先检查当前输入方案是否仍是普通全拼或其他不支持九键的方案。九键需要**方案与皮肤同时匹配**，不是在「中文九键符号设置」里打开一个开关即可。

### 有中文候选，拼音却显示成数字

这通常需要检查九键方案的预编辑配置及候选注释是否被方案脚本清除。请参考[中文九键配置](/apps/hamster/v3/docs/guides/chinese-ninekey-configuration/)，不要只调整应用中的候选字号。

## 方案、词库或补丁修改后，怎么让键盘生效

**入口：元书首页 →「RIME」→「部署」旁的「运行」。**

1. 先保存方案、词库或补丁文件。
2. 确认修改的是当前使用的方案目录。
3. 运行「部署」，等待完成；失败时查看「RIME → 日志」。
4. 回到输入框，重新唤起元书键盘测试。

元书的应用文件与键盘读取的文件不是简单的同一份。通过文件管理、Wi-Fi 或网络存储改了应用文件后，仍需要部署。部署不是“重置方案”，不会以还原内置方案为目的覆盖你的整套方案。

## 简繁切换选项怎么设置

**入口：「RIME」→「简繁切换」。**

这里的配置需要与当前方案中的简繁转换选项匹配，默认对应内置雾凇方案。第三方方案可能使用不同的 option 名称；填写前先查该方案的说明，不能假定所有方案都能沿用同一名称。

这不是更换词库的入口，也不能替没有简繁转换配置的方案自动补齐转换功能。

## RIME 其他选项有什么用

| 选项 | 用途与提醒 |
| --- | --- |
| 同步 | 同步自造词等 RIME 数据；先配置同步文件路径与设备唯一名称，见[文件与同步](/apps/hamster/v3/docs/guides/settings/files-sync/) |
| 复制文件至 iCloud | 将相应文件复制到 iCloud；不是自动合并用户词 |
| 自动从 iCloud 复制文件 | 开启后，部署或同步前会先从 iCloud 获取 RimeUserData 路径下的文件；不希望云端旧文件参与时，先核对这项 |
| 禁止复制键盘文件 | 不需要自造词等数据复制时才考虑；依赖这些数据的用户不要为排错随意打开 |
| 键盘显示 RIME 通知 | 控制键盘里的 RIME 通知提示 |
| 日志 | 排查部署失败、方案加载失败等问题 |
| 方案重置 | 切回默认 `rime-ice`，重建应用侧共享目录和默认方案目录，并替换键盘侧对应目录；不是普通的刷新按钮 |

:::danger[方案重置会覆盖哪些内容]
重置会将当前方案路径切回 `rime-ice`，删除并重建应用侧 `RimeSharedSupport` 和 `RimeUserData/rime-ice`，随后替换键盘侧对应的 RIME 目录。默认方案目录内的个人补丁、词库修改，以及尚未回收的键盘侧数据可能丢失；其他应用侧方案子目录不会因此被整体删除。

执行前先妥善回收键盘侧最新用户词、另存个人修改，再备份。只点击「备份」不保证包含键盘侧最新数据，范围限制见[备份、恢复与重置](/apps/hamster/v3/docs/guides/settings/backup-reset/)。
:::

## LevelDB 是不是切换词库的入口

首页的「LevelDB」面向需要查看、管理 RIME 用户数据库或脚本数据库的进阶用户。普通切换方案不需要操作它。不了解键值含义时，不要删除或修改数据库记录；涉及用户词迁移时，优先使用 RIME 同步并保留备份。
