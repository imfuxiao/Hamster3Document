---
title: 剪贴板、粘贴提示条与验证码设置
description: 开启剪贴板监听和粘贴提示，自动提取验证码，调整记录数量、排序和后台画中画监听。
---

**入口：元书首页 →「剪贴板」→「设置」。** 剪贴板属于 Pro 扩展功能，在键盘中使用还需要系统授予元书「允许完全访问」。

## 复制后，怎么在键盘上看到粘贴提示

按下面的顺序开启：

1. 在系统「设置 → 通用 → 键盘 → 键盘 → 元书」开启「允许完全访问」。
2. 进入元书「剪贴板 → 设置」，打开「键盘监视系统剪贴板」。
3. 再打开「剪贴板提示条」。
4. 确认当前皮肤提供工具栏，再复制一段新文字，打开普通应用输入框中的元书键盘。
5. 提示条显示后，点按即可粘贴。

「剪贴板提示条」依赖前一个监听开关。它是灰色时，先打开监听，而不是反复点击灰色开关。提示条显示在键盘工具栏中；皮肤没有工具栏时，即使开关已打开，也没有可显示提示条的位置。安全输入框中不显示提示条。

## 怎么只粘贴验证码，不粘贴整条短信

在上述两个开关均开启后，再打开「自动提取验证码」。

当**键盘监听读到新的复制文字并成功识别验证码**，且当前主皮肤具有工具栏样式、输入框不是安全输入框时：

- 提示条显示提取出的验证码。
- 系统剪贴板会被更新为验证码。
- 本次键盘监听不把原始整段文字写入元书剪贴板记录。

此自动提取只作用于键盘监听读取文字的过程，画中画监听或其他读取途径不经过这项提取处理；已经由其他途径保存的原文也不会因此被删除。

:::caution[这会改变系统剪贴板内容]
开启提取后，其他应用中的“粘贴”也可能得到验证码，而不是原来的整段文字。如果需要保留通知全文，请关闭此功能后重新复制原文。此功能处理的是你复制的文字，不是让元书主动读取所有短信。
:::

### 为什么自动提取验证码的开关是灰色

三个开关有依赖顺序：

**键盘监视系统剪贴板 → 剪贴板提示条 → 自动提取验证码。**

先确认前两项已开启。前置开关关闭时，下游选项暂时不可操作，不表示 Pro 购买状态一定有问题。

## 剪贴板会一直在后台记录吗

要区分两种监听方式：

| 功能 | 什么时候工作 | 怎么结束 |
| --- | --- | --- |
| 键盘监视系统剪贴板 | 元书键盘显示期间持续监视变化 | 收起键盘，或关闭此开关 |
| 系统剪贴板监视 | 手动打开画中画窗口后，可在应用后台或不显示键盘时监视变化 | 关闭画中画窗口 |

若需要第二种方式，在「剪贴板 → 设置 → 系统剪贴板监视」点「开启」。不需要继续收集时，关闭画中画窗口。

不要把“打开了键盘监听”理解为不显示键盘、没有画中画窗口时也会无限后台采集。iOS 的剪贴板访问提示和权限行为仍受系统控制。

## 剪贴板只能保存少量内容，怎么调整

**入口：「剪贴板 → 设置 → 剪贴板最大存储数量」。**

使用加减控件调整。当前界面范围为 **20～200**，每次增减 **5**。不要把剪贴板历史当作长期备份；需要长期使用的文字，建议保存到常用语或另外导出。

## 为什么用过一条记录后，它跑到最前面

检查「自动排序」：

- **开启**：最近使用的记录排在前面。
- **关闭**：收藏置顶，其余按复制时间从新到旧固定排列。

希望列表稳定、不因点击而变动，可关闭自动排序。需要放大记录列表文字时，调整同页「剪贴板字体」，而不是候选字字号。

## 清理剪贴板与保存常用语

剪贴板列表菜单支持：

- **清空剪贴板**：清空记录，确认前先导出需要保留的内容。
- **清空非收藏项**：只清理非收藏记录；重要内容仍建议另存，不要只依赖收藏。
- 将记录保存为常用语：确认提示中会说明同时从剪贴板删除，操作前看清提示。

## 开了开关，仍没有提示条怎么办

1. 确认使用的是元书键盘，已解锁相应 Pro 功能并开启完全访问。
2. 按依赖顺序检查监听和提示条开关。
3. 检查当前皮肤是否提供工具栏；没有工具栏时，换用带工具栏的皮肤对照。
4. 在非安全输入框中重新复制一段**新的普通文字**测试，不只使用原来的验证码。
5. 检查系统是否要求确认剪贴板访问。
6. 在备忘录中对照，区分特定应用限制。

想关闭复制后的键盘提示，只关闭「剪贴板提示条」即可；完全不希望键盘继续监听时，关闭「键盘监视系统剪贴板」，并确认画中画监视窗口也已关闭。
