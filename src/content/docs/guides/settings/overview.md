:::note[适用范围]
本组文档按 **2026 年 10 月 30 日本地 Hamster3 项目的 iOS 界面代码与简体中文文案**整理，不代表所有选项都已在商店版本上线。旧版应用、TestFlight 与商店版可能存在名称或位置差异；找不到选项时，请先在「关于」确认版本。本文不是 Android 或 macOS 的设置说明。

## 刚安装，先做这三件事

1. **添加键盘**：系统「设置」→「通用」→「键盘」→「键盘」→「添加新键盘…」→「元书」。
2. **按需授权**：在系统键盘列表中点「元书」，开启「允许完全访问」。按键震动、自造词写入、剪贴板及联网功能需要此权限。
3. **切换键盘**：在备忘录等应用中长按键盘上的地球图标，选择「元书」，输入一句话确认能正常打字。

详细步骤见[开启元书键盘](/apps/hamster/v3/docs/guides/enable-keyboard/)。密码框或禁用第三方键盘的应用可能强制使用系统键盘，这不是元书的设置失效。

## 看懂首页的入口

- **输入方案卡片**：查看当前方案与目录，进入「输入方案」。方案决定怎么把编码变成文字。
- **键盘皮肤**：决定键盘外观和布局；只换皮肤，不会自动把全拼方案变成双拼或九键方案。
- **输入与按键**：包含键盘设置、输入行为、按键音与震动、键盘字体、工具栏设置、键盘菜单设置、符号栏设置。
- **文件管理**分组：包含文件管理、Wi-Fi 文件传输、网络存储、LevelDB、备份与恢复。
- **扩展功能 · PRO**：包含常用语、剪贴板、脚本、命令面板、跟打练习。使用受限时先检查 Pro 状态。
- **其他**：包含键盘预览、应用图标、关于。

手机上通常是单列页面，iPad 可能以侧栏加详情的方式展示。同名入口的用途相同，不必因为页面排列不同寻找另一套设置。

## 设置后怎么生效

| 修改内容 | 后续操作 |
| --- | --- |
| 界面中的开关、字号、颜色等 | 一般直接保存；回到输入框，收起并重新唤起元书键盘检查 |
| 有「保存」按钮的编辑页 | 点击「保存」，不要只返回或关闭页面 |
| 键盘高度、键盘工具栏排列、返回主键盘／数字键盘／中文九键符号列表 | 在对应设置页明确点击「保存」 |
| RIME 方案、词库、补丁文件 | 修改应用目录后，进入「RIME」运行「部署」，等待成功 |
| 从网络存储下载方案文件 | 下载只更新应用目录；仍需运行「部署」 |
| RIME 用户词 | 使用「RIME → 同步」，不是仅复制方案目录 |

:::caution[不要把重置当作刷新]
「重置应用设置」「方案重置」「重置内置键盘」「恢复备份」不是同一件事。排查问题时先保存备份，优先只调整有问题的项目，不要连续执行多个重置。
:::
