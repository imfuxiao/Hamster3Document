title: 输入行为、自动空格与符号设置
description: 设置符号成对、双击空格句号、中英数字自动空格、返回主键盘以及数字和九键的符号列表。
---

**入口：元书首页 →「输入行为」。** 这里控制文字上屏时的处理方式，以及部分键盘的符号列表；键盘大小、颜色和候选字号不在这里设置。

## 输入左括号时，怎么自动补上右括号

打开「符号成对」。未选中文字时，对支持配对的符号，输入左侧符号后会补上右侧符号，并将光标放在中间，便于继续输入正文。

如果不希望在没有选区时输入括号、引号后自动补全，关闭此开关。**有选中文字时，用成对符号包围选区是另一种处理，不受此开关控制**，关闭后仍可能出现右侧符号。若没有选区仍一次出现两个符号，再检查皮肤按键或 RIME 方案是否本身就输出整对符号，应用开关不能删除方案已经输出的内容。

**验证方法：** 在备忘录中不选中文字，输入一个左括号，观察是否自动补全及光标是否在括号中间。

## 怎么关闭双击空格变句号

关闭「双击空格输入句号」；希望启用则打开。

测试时先输入并确认一段文字，再快速连续点按空格。中文和 ASCII 内容后的句号处理可能不同；不要在仍有候选字时，把第一次空格选词当作已经输入了一个空格。

## 中文和英文、数字之间怎么自动加空格

这两个开关相互独立，按需开启：

| 选项 | 希望得到的排版效果 |
| --- | --- |
| 中文与数字间添加空格 | `购买3个` → `购买 3 个` |
| 中文与英文间添加空格 | `使用RIME输入` → `使用 RIME 输入` |

上表以中文、英文或数字**分次上屏**为前提，例如依次上屏「购买」「3」「个」。自动空格只检查本次上屏文本与光标前后已有文本的边界，不处理本次字符串内部；一次性上屏或粘贴 `购买3个` 时，不会自动为其内部补空格，也**不是对整篇已输入文章执行格式化**。开关默认关闭；不想自动改动文字时，保持关闭即可。

### 为什么打开了自动空格，某些地方仍不加

这是输入时的文字处理，存在以下限制：

- 不会扫描本次上屏字符串内部，也不会回头改写整篇旧文本。
- 英文字母与数字只识别 ASCII 字符（`A–Z`、`a–z`、`0–9`），不包含全角字母或数字。
- 选中文字再替换时，不执行自动空格处理。
- 在普通应用输入框中，安全输入框，以及应用声明为网址（`URL`）、邮箱（`emailAddress`）、数字键盘（`numberPad`）、电话（`phonePad`）、网页搜索（`webSearch`）的输入框不执行自动空格处理。这依赖应用声明的键盘类型，不代表所有数字类或搜索类输入框都禁用；例如小数键盘（`decimalPad`）不在这份排除列表中。
- 能否正确识别文字边界，也与当前应用向键盘提供的上下文有关。

请先在备忘录的普通文本框测试，不要只在搜索框、网址栏中判断是否生效。

## 输入标点后，怎么自动返回主键盘

**入口：「输入行为」→「返回主键盘符号设置」。**

1. 打开「是否返回主键盘」。
2. 在下方列表保留希望触发返回的符号，使用「新增」添加需要的符号。
3. 不想触发返回的项目可从列表中删除。
4. 编辑完列表后点击「保存」，不要只返回上一页。开关本身即时保存，列表修改则需要单独保存。

在符合条件的键盘中输入列表里的符号后，会返回主键盘。这里的列表是**触发返回的符号**，不是所有符号的总词库。

:::note[符号键盘是另一套规则]
页面注明此选项仅对「非符号键盘」有效。符号键盘是否留在当前页面由它的锁定状态控制；如果希望连续输入多个符号，应检查符号键盘上的锁定操作，而不是只修改这个列表。
:::

## 数字键盘旁边的符号怎么修改

**入口：「输入行为」→「数字键盘符号设置」。**

在列表里添加需要的符号、编辑各行内容或删除不需要的项目。当前页面没有排序控件，也不支持拖动排序；可通过编辑各行内容，或删除后按顺序重新添加来调整。完成后点击「保存」，直接返回不会保存列表修改。

「启用 Symbol Action 类型」决定列表符号是否交给 RIME 处理：

| 状态 | 行为 |
| --- | --- |
| 关闭 | 默认使用 Character Action，交由 RIME 处理，结果可能受当前方案影响 |
| 开启 | 使用 Symbol Action，适合希望直接输出符号、不让 RIME 处理的情况 |

如果点逗号却得到方案转换后的另一个符号，可以对照此开关测试；不要因此替换整套词库。

## 中文九键旁边的符号怎么修改

**入口：「输入行为」→「中文九键符号设置」。**

可以维护九键的符号列表，以及：

- **启用 Symbol Action 类型**：含义与数字键盘相同。
- **是否显示符号添加按键**：控制九键符号列表底部的添加入口。

编辑完符号列表后需点击「保存」；上面的开关则即时保存。这里只调整九键相关符号，**不能把全拼方案变成九键方案**。九键键盘只能输入数字时，请看[输入方案与 RIME](/apps/hamster/v3/docs/guides/settings/rime/)。

## 修改了符号，键盘上却没变化

先确认列表编辑完成后已点击「保存」，再确认自己修改的是哪一种符号入口：

- 数字键盘符号列表：本页「数字键盘符号设置」。
- 中文九键符号列表：本页「中文九键符号设置」。
- 悬浮在键盘上方的快捷符号条：首页「符号栏设置」。
- 皮肤按键上的角标、上下滑动或长按符号：由皮肤配置决定。

它们不是同一份列表，修改一个入口不会替换全部位置。悬浮符号栏见[工具栏、菜单与符号栏](/apps/hamster/v3/docs/guides/settings/toolbar-menu/)。
