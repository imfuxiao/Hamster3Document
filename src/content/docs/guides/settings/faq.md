## 找不到教程里的设置怎么办

先在「关于」检查版本。本组教程按 2026 年 10 月 30 日本地 iOS 项目界面整理，部分选项可能尚未进入商店版；Android、macOS 或旧版界面也可能不同。

再检查是否需要进入子页面：例如剪贴板与字体都有自己的「设置」页面，工具栏也有独立的总开关。不要只在应用首页寻找每一个开关。

## 某个选项不显示或是灰色，是否一定没买 Pro

不一定。常见的是前置选项尚未满足：

| 不显示或不可操作的项目 | 先检查 |
| --- | --- |
| 剪贴板提示条 | 是否开启「键盘监视系统剪贴板」 |
| 自动提取验证码 | 是否同时开启监听与剪贴板提示条 |
| 内嵌卡片下的显示候选字栏、预编辑设置 | 是否开启「内嵌输入模式」 |
| 隐藏候选栏首个候选项 | 显示内容是否为首个候选项，或预编辑文本与首个候选项 |
| 内嵌预编辑文本的候选序号 | 显示内容是否包含全部候选项 |
| 显示分页按键 | 是否选择「手动分页」 |
| 隐藏候选栏展开按键 | 是否手动分页，且已经开启显示分页按键 |
| 工具栏的 AI 指令可选项 | 是否先创建了 AI 指令，相关提示词与服务商是否有效 |

## 改了设置，键盘还是没变化

依次检查：

1. 当前是否确实在使用元书键盘；长按地球图标确认。
2. 编辑页是否需要点「保存」，特别是键盘高度、工具栏排列，以及返回主键盘、数字键盘和中文九键的符号列表。
3. 收起后重新唤起键盘，先在备忘录普通文本框测试。
4. 是否改错区域，例如预编辑注释与候选栏注释是两个设置。
5. 如果改的是方案文件，是否改在当前目录，并完成 RIME 部署。
6. 是否有自定义工具栏覆盖皮肤工具栏，或 iCloud 文件复制影响了本地版本。

不要同时修改多个开关或连续重置，这会让原因更难判断。

## 想放大候选字，不想放大整块键盘

到「键盘设置 → 候选文字」调整字号；不要只调整「键盘高度设置」。字号、字体与键盘高度是不同设置。详见[键盘与候选栏](/apps/hamster/v3/docs/guides/settings/keyboard/)。

## 隐藏了候选注释，为什么另一处仍显示拼音

「候选文字 → 候选 Comment」控制候选栏；「内嵌输入模式 → 预编辑 → 显示候选注释」控制当前应用输入框中的内嵌预编辑文本，不是键盘自身的预编辑区。先确认想隐藏的是哪个区域，不必修改或删除词库。

## 候选栏、展开按钮或首个候选词不见了

- 候选栏不见：检查「内嵌输入模式 → 显示候选字栏」。
- 展开按钮不见：检查手动分页设置下的「隐藏候选栏展开按键」。
- 首个候选项不在候选栏中：检查是否启用「隐藏候选栏首个候选项」，它可能仍在当前应用输入框中的内嵌预编辑文本里显示。

这些开关隐藏的是显示入口或重复项，不应先判断为词库丢失。

## 九宫格只能打数字，怎么修复

先核对两项是否同时正确：**支持中文九键的输入方案 + 对应 T9 皮肤**。更改九键符号列表不能解决方案不匹配。见[输入方案、双拼九键与 RIME](/apps/hamster/v3/docs/guides/settings/rime/)。

## 声音或震动打开了，为什么没有效果

- 没声音：查看「按键音与震动」页的静音模式提示，再检查音量。
- 没震动：检查系统是否授予元书「允许完全访问」、设备是否支持，以及反馈强度。
- 只有一个皮肤不行：切换内置皮肤对照。

详见[按键音与震动设置](/apps/hamster/v3/docs/guides/settings/sound-haptics/)。

## 字体文件导入了，为什么没变

还需将它加入「键盘字体」配置列表，并在「设置」中打开「启用键盘字体」。字体不包含的字形、字符范围限制和字体顺序也会影响显示。见[皮肤与字体](/apps/hamster/v3/docs/guides/settings/skins-fonts/)。

## 工具栏项已添加，为什么键盘上找不到

还要把项目放到「键盘工具栏」，点击「保存」，并在「设置」中打开「启用自定义工具栏」。只新增项目不等于放入了实际工具栏。见[工具栏与菜单](/apps/hamster/v3/docs/guides/settings/toolbar-menu/)。

## 自动空格开启后，网址栏等专用输入框不生效

在安全输入框，以及应用声明为网址、邮箱、数字键盘（`numberPad`）、电话或网页搜索的输入框中，这是预期限制。判断依据是应用声明的键盘类型，并非所有数字类或搜索类输入框都禁用，例如小数键盘（`decimalPad`）不在排除列表中。自动空格只处理本次上屏文本与前后已有文本的边界，不处理本次字符串内部，也不会批量重排已有全文。先在普通文本框中分次输入中文与 ASCII 字母、数字验证。见[输入行为](/apps/hamster/v3/docs/guides/settings/input-behavior/)。

## 复制整条通知后，为什么粘贴只剩验证码

检查「剪贴板 → 设置 → 自动提取验证码」。监听、提示条与提取开关均开启，当前主皮肤提供工具栏样式，且输入框不是安全输入框时，键盘监听成功识别出的验证码会写回系统剪贴板，本次读取不记录原文。画中画等其他读取途径不经过这项自动提取处理。需要整段内容时关闭提取后重新复制。见[剪贴板设置](/apps/hamster/v3/docs/guides/settings/clipboard/)。

## 网络存储下载成功，为什么键盘方案没更新

下载只修改应用文件，还需在「RIME」中运行「部署」。网络存储也不是自动双向同步，同名文件可能被覆盖。见[文件与同步](/apps/hamster/v3/docs/guides/settings/files-sync/)。

## 打开 iCloud 备份后，旧备份列表空了

iCloud 目录可用时，开启开关会切换当前备份路径，但不会自动迁移旧文件。切回原位置检查，不能仅凭列表为空断定文件被删。另外，无法取得 iCloud 备份目录时会回退本机，不能仅凭开关开启判断已有云端副本。见[备份、恢复与重置](/apps/hamster/v3/docs/guides/settings/backup-reset/)。

## 买了 Pro，为什么 AI 还是不能用

Pro、系统完全访问权限、模型服务商的 Token 和调用额度是不同条件。先在「命令面板 → 服务商与模型」保存 Token，执行连接测试，再检查 AI 指令引用。见[扩展功能设置](/apps/hamster/v3/docs/guides/settings/extensions/)。

## 排查后仍不行，反馈时带什么

建议提供：

- 元书版本与商店／TestFlight 来源、iOS 版本、设备型号。
- 当前输入方案名称、方案目录，以及皮肤名称。
- 从哪个入口修改了哪个选项，是否保存和重新唤起键盘。
- 预期效果、实际结果，以及是否能在备忘录中复现。
- 不含隐私内容的截图；部署问题可附相关错误日志。

不要公开发送 API Token、密码、私人剪贴板全文或完整备份。反馈前保留现状，避免为复现问题误删自己的数据。
