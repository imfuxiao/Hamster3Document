常用语用来保存那些需要反复输入的文字：邮箱、地址、身份证号、客服话术、Markdown 片段等等。保存之后，可以在键盘的常用语面板中点选上屏，也可以绑定到按键、写进命令面板，一次点击即可写入正在输入的 App。

常用语的正文支持**模板变量**，可以在上屏时动态填入日期、农历、自定义内容，并指定上屏后光标停留的位置。

<Aside title="使用前提" type="caution">
常用语保存在 App Group 共享容器中，键盘需要开启**完全访问**权限才能读取。未开启时，键盘中的常用语面板会是空的，`phrase` 指令也会提示「未找到常用语」。
</Aside>

## 一、在应用中管理常用语

打开元书 App，在**扩展功能**分组中点击**常用语**，即可进入常用语主页面。

页面顶部是搜索框与筛选按键，下方按**分类**分组展示所有常用语。

右上角的按键依次为：

- **折叠 / 展开全部**：收起或展开所有分类分组；
- **＋**：新建一条常用语；
- **⋯**：变量管理、标签管理、分类管理、导入、导出、批量选择。

### 新建与编辑

点击右上角 **＋** 新建，或点击列表中已有的条目进入编辑页。编辑页包含以下部分：

| 区域 | 说明 |
| --- | --- |
| 标题 | 可选。但 `phrase` 指令是**按标题**查找常用语的，需要绑定到按键时必须填写 |
| 常用语 | 正文，支持模板变量；点击标题右侧的**预览**可以看到变量渲染后的实际效果 |
| 新增变量 | 四个快捷按键：日期、时间、光标、自定义，点击后把对应变量插入到正文光标处 |
| 标签 | 一条常用语可以有多个标签，用于筛选 |
| 分类 | 一条常用语只能属于一个分类，决定它在列表中的分组位置 |

填写完成后点击**保存**。

### 分类

分类用于常用语列表的分组展示，一条常用语只能属于一个分类，没有指定分类的会归入**未分类**分组。

在 **⋯ → 分类管理** 中可以新建、重命名、删除分类，并手动调整分类的排列顺序，这个顺序就是常用语主页面与键盘面板中分组的顺序。

### 标签

在 **⋯ → 标签管理** 中可以新建标签并为其指定颜色。标签与分类不同，一条常用语可以同时带多个标签，主要用于搜索与筛选（键盘面板与命令面板中都可以按标签过滤）。

### 收藏、筛选与批量操作

- 主页面的搜索框可以按标题与正文搜索；
- 点击搜索框右侧的筛选按键，可以展开**收藏过滤**与**标签过滤**；
- 点击分组标题可以折叠 / 展开该分组；
- **⋯ → 选择**进入多选模式，可批量**归类**（把选中的常用语移动到某个分类）或批量删除。

## 二、模板变量

常用语的正文中，凡是写成 `{{变量名}}` 的部分，都会在上屏时被替换成变量的取值。

### 内置日期变量

- 公历：`{{date:时间格式}}`
- 农历：`{{lunar_date:时间格式}}`
- 生肖：`{{lunar_zodiac}}`

常用写法：

| 写法 | 输出示例 |
| --- | --- |
| `{{date:yyyy-MM-dd}}` | `2020-12-31` |
| `{{date:yyyy/MM/dd}}` | `2020/12/31` |
| `{{date:HH:mm}}` | `12:59` |
| `{{date:HH:mm:ss}}` | `12:59:59` |
| `{{date:MMM d, yyyy}}` | `12月 31, 2020` |
| `{{date:eeee}}` | `星期一` |
| `{{date:eee}}` | `周一` |
| `{{lunar_date:U}}` | `丙午` |
| `{{lunar_date:U年MMMd}}` | `丙午年七月廿四` |
| `{{lunar_zodiac}}` | `马` |

编辑页的**日期**与**时间**按键提供了上面这些常见格式的快捷插入，也可以直接手写任意时间格式。

#### 时间格式中预定义的字符串含义：

- 年：用 y 表示当前年份

  - yy：2位数字表示年，如 `26`
  - yyyy：年，四位表示法，如 `2026`
  - U：表示中文年份，如 `丙午`，需搭配 `lunar_date` 使用，如 `{{lunar_date:时间格式}}`

- 季度：用 q 表示表示当前季度

  - q：1位数字表示季度，如第三季度为 `3`
  - qq：2位数字表示季度，如第三季度为 `03`
  - qqq：数字加后缀`季度`，如第三季度为 `3季度`

- 月：用 M 表示当前月份

  - M：用最少1位数字表示月份，一月对应 `1`，十二月对应 `12`
  - MM：2位数字表示月份，不够两位的月份会补 `0`，如一月对应 `01`
  - MMM：
    - 公历（date）：数字加后缀`月`，如一月对应 `1月`
    - 农历（lunar_date）：汉字加后缀`月`，如`七月`
  - MMMM：汉字加后缀`月`，如`一月`

- 周：用 w 表示当年周数，用 W 表示当月周数

  - w：用最少1位数字表示周，如当年第一周对应 `1`，当年第35周对应 `35`
  - ww：用最少2位数字表示周，不足两位的周会补 `0`，如当年第一周对应 `01`
  - W：用数字表示当月周数，如当月第一周对应 `1`

- 天：用 d 表示当月天数，用 D 表示当年天数
  - d：
    - 公历（date）：用最少1位数字表示当月天数，如当月第2天对应 `2`
    - 农历（lunar_date）：用中文汉字表示当月天数，如24号对应`廿四`
  - dd：
    - 公历（date）：用最少2位数字表示当月天数，如当月第2天对应 `02`
    - 农历（lunar_date）：用中文汉字表示当月天数，如24号对应`廿四`
  - D：用最少1位数字表示当年天数，如当年第2天对应 `2`
  - DD：用最少2位数字表示当年天数，如当年第2天对应 `02`
  - DDD：用最少3位数字表示当年天数，如当年第2天对应 `002`

- 周天：用 `e` 表示当前周的天数

  - e：用最少1位数字表示当前周的第几天，如星期五对 `5`。
  - ee：用最少2位数字表示当前周的第几天，如星期五对 `05`。
  - eee: 汉字`周`加汉字天数表示当前周的第几天，如当前周的第5天对应 `周五`
  - eeee: 汉字表示当前周的第几天，如当前周的第5天，对应`星期五`
  - eeeee: 汉字表示当前周的第几天，如当前周的第5天，对应`五`

- 上午/下午：用 `a` 表示当天的上午还是下午，`B`表示上午、下午、中午、晚上

  - a: 当天上午对应 `上午`，当天下午对应 `下午`
  - B：表示当天4个时间段：上午、下午、中午、晚上
  
- 小时：用 `h` 表示当前时间点（12小时计时），用 `H` 表示当前时间点（24小时计时）

  - h：用最少1位数字表示当前时间点，如1点对应 `1`
  - hh：用最少2位数字表示当前时间点，如1点对应 `01`
  - H：用最少1位数字表示当前时间点，如上午1点对应 `1`，下午1点对应 `13`
  - HH：用最少2位数字表示当前时间点，如上午1点对应 `01`，下午1点点对应 `13`
  
- 分钟：用 `m` 表示当前时间点的分钟

  - m：用最少1位数字表示当前时间点的分钟，如当前1点过9分对应 `9`
  - mm：用最少2位数字表示当前时间点的分钟，如当前1点过9分对应 `09`

- 秒：用 `s` 表示当前时间点的秒

  - s：用最少1位数字表示当前时间点的秒，如当前1点9分9秒对应 `9`
  - ss：用最少2位数字表示当前时间点的秒，如当前1点9分9秒对应 `09`


<Aside title="提示" type="tip">
注意：
- 农历下 `y` 不是年份而是甲子序号，要输出年份请用 `U`（干支年，如`丙午`）。
- 时间格式参考： [Unicode UTS #35 — Date Format Patterns](https://unicode.org/reports/tr35/tr35-dates.html#Date_Format_Patterns)，此手册中的时间格式不是全部都支持，文档中列举到是已经测试支持的
</Aside>

### 系统剪贴板与选中文本变量

- 系统剪贴板：`{{pasteboardContent}}`
- 键盘宿主应用选中文本：`{{selectedText}}`

### 光标变量

`{{cursor}}` 用来指定上屏后光标停留的位置，一条常用语中只需要写一处。

例如要输入一对 Markdown 强调标记，并让光标落在中间：

```text
::{{cursor}}::
```

上屏后得到 `::::`，光标正好停在两组标记之间，可以直接接着输入。

### 自定义变量

在 **⋯ → 变量管理** 中可以新建自己的变量，每个变量包含变量名、变量值与**安全**开关。

例如新建一个变量名为 `邮箱`、变量值为 `123@123.com` 的变量，在正文中写：

```text
我的邮箱是 {{邮箱}}
```

上屏后得到 `我的邮箱是 123@123.com`。

变量名中可以包含 `.`、空格和逗号，例如 `{{公司 邮箱}}` 是合法的。

自定义变量的值也可以写成 `date:时间格式`，此时它等价于一个日期变量，例如变量值填 `date:yyyy-MM-dd`，引用时就会输出当天日期。

<Aside title="安全变量" type="caution">
打开变量的**安全**开关后，导出时该变量只会导出变量名，不会导出变量值（备份功能不受影响）。适合放身份证号、账号一类不希望随文件分享出去的内容。
</Aside>

同名时，自定义变量优先于内置日期变量。

## 三、在键盘中使用

### 常用语面板

快捷指令 `#showPhraseView` 会打开常用语面板：

```yaml
action: { shortcut: "#showPhraseView" }
```

面板顶部是**常用语 / 剪贴板**分段控件，可以随时切换；右上角的菜单提供：

- **锁定面板**：锁定后，上屏一条常用语不会关闭面板，可以连续上屏多条；
- **仅收藏 / 全部**：只显示收藏的常用语；
- **标签**：按标签筛选，可多选；
- **分类**：按分类筛选，可多选。

点击一条常用语即上屏，正文中的变量会先渲染，`{{cursor}}` 会决定光标落点；未锁定面板时上屏后面板自动关闭。

长按一条常用语可以：

- **添加标签**：直接在键盘里给它打标签；
- **编辑**：跳转回元书 App 并打开这条常用语的编辑页；
- **打开链接**：正文中含网址时出现，用浏览器打开。

在**剪贴板**分段中长按一条记录，选择**存为常用语**，可以把剪贴板内容直接保存成常用语。

### 绑定到按键

`phrase` 指令按**标题**取出常用语并上屏：

```yaml
action: { phrase: '常用语 title' }
```

前提是这条常用语填写了标题。标题重名时会取列表中排在最前的那条（收藏优先，其次按手动排序与时间）。

如果只是想直接上屏一段固定模板，不希望先建一条常用语，可以用 `snippet` 指令，把模板内容直接写在指令里：

```yaml
action: { snippet: '这是一个日期：{{date:yyyy-MM-dd}}' }
```

`snippet` 支持与常用语完全相同的变量（含自定义变量与 `{{cursor}}`）。两条指令的详细说明见[按键动作](/apps/hamster/v3/docs/guides/skins/action/#常用语)。

### 命令面板

在[命令模式](/apps/hamster/v3/docs/guides/command-mode/)中输入常用语前缀（默认 `/`），即可按标题、正文和标签搜索常用语，点击或按确认键上屏。

## 四、导入与导出

主页面 **⋯ → 导出**可以选择要导出的常用语，生成 `export_phrase.yaml`；**⋯ → 导入**选择一个 YAML 文件即可导入。

导出文件同时包含常用语、变量、标签和分类：

```yaml
phrases:
  - title: 邮箱
    content: 我的邮箱是 {{邮箱}}
    isFavorite: true
    category: 个人信息
    tags:
      - name: 工作
        color: "#FF9500"
phraseVariables:
  - key: 邮箱
    value: 123@123.com
    isSecure: false
phraseTags:
  - name: 工作
    color: "#FF9500"
phraseCategories:
  - name: 个人信息
    sort: 0
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `title` | 标题，`phrase` 指令按它查找 |
| `content` | 正文，可含模板变量 |
| `isFavorite` | 是否收藏 |
| `category` | 所属分类名称，留空表示未分类 |
| `tags` | 标签列表 |
| `isSecure` | 变量是否为安全变量，为 `true` 时 `value` 导出为空 |

## 五、常见问题

**按键提示「未找到常用语」**

`phrase` 指令按标题精确匹配。请确认这条常用语填了标题，且指令中的标题与它完全一致（改过标题的话，按键上的配置也要同步修改）。

**正文里的一段内容上屏后凭空消失**

检查是否写了不存在的变量名。未定义的变量会被渲染成空字符串。可以在编辑页点击**预览**先确认渲染结果。
